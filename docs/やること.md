## Phase 1: Grafana を ArgoCD でデプロイ ← いまここ

前提: k3s に接続でき、ArgoCD インストール済み、本リポジトリは public。

- [ ] 変更を GitHub `main` に push(ArgoCD はそこを読む)
- [ ] 親 Application を一度だけ登録
  ```bash
  kubectl apply -f bootstrap/root-app.yaml
  ```
- [ ] 同期を確認(root / grafana が `Synced` かつ `Healthy`)
  ```bash
  kubectl -n argocd get applications
  ```
- [ ] Grafana Pod が Running
  ```bash
  kubectl -n monitoring get pods
  ```
- [ ] 管理者パスワードを取得(user: `admin`)
  ```bash
  kubectl -n monitoring get secret grafana -o jsonpath="{.data.admin-password}" | base64 -d ; echo
  ```
- [ ] ブラウザで確認(port-forward)
  ```bash
  kubectl -n monitoring port-forward svc/grafana 3000:80   # http://localhost:3000
  ```

> 困ったとき: `kubectl -n argocd describe application grafana`(同期エラー)/
> `kubectl -n monitoring describe pod <pod名>` の Events(起動失敗の原因)。

## Phase 2: Authentik(SSO)を追加 — Secret は SOPS/KSOPS

Grafana 検証が済んでから着手する。public リポジトリなので機微情報は暗号化して管理する。
参考構成: https://github.com/shinbunbun/k8s-apps(SOPS + KSOPS)。

やること(この順):

- [x] `brew install age` + age 鍵ペア生成(秘密鍵: `~/.config/sops/age/keys.txt`)
- [x] `.sops.yaml` に age ルール追記(公開鍵 `age1llr97...lttrng` / `secrets/*.enc.yaml`)
- [x] `apps/authentik/application.yaml`(Helm, chart `2026.5.6`, 同梱PostgreSQL, Redis無し, existingSecret)
- [x] `apps/authentik/secrets/authentik-secret.enc.yaml` を生成・暗号化(secret_key / DBパス / bootstrapパス)
- [ ] age 秘密鍵をクラスタに Secret 登録:
      `kubectl -n argocd create secret generic sops-age --from-file=keys.txt=$HOME/.config/sops/age/keys.txt`
- [ ] **ArgoCD repo-server に KSOPS を組み込む**(init コンテナ + `SOPS_AGE_KEY_FILE` マウント)← 最大の山場
- [ ] `apps/authentik/secret-app.yaml` を追加(`apps/authentik/secrets` を kustomize+ksops で処理)
- [ ] push して authentik が Synced/Healthy になるか確認

編集メモ:
- 暗号化: `sops -e -i apps/authentik/secrets/authentik-secret.enc.yaml`(平文を作って -i で上書き暗号化)
- 復号/編集: `export SOPS_AGE_KEY_FILE=~/.config/sops/age/keys.txt` してから `sops apps/authentik/secrets/authentik-secret.enc.yaml`
- 初期管理者: `akadmin` /(暗号化Secret内の AUTHENTIK_BOOTSTRAP_PASSWORD）
- age 秘密鍵 `~/.config/sops/age/keys.txt` はマスターキー。**バックアップ必須**(紛失=復号不能)

## メモ

- アプリ追加は `apps/<name>.yaml`(または `apps/<name>/`)を足して push するだけ。
  `root` Application が自動検知して同期する。
- アプリ削除は `apps/` 配下を消して push すると prune で自動削除される。
